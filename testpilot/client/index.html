            Academic Focus: AI-Generated vs Manually Written Test Cases
          

          

            As outlined in the BITS Pilani project proposal, the academic centerpiece is revealing where AI excels and where it misses in high-stakes healthcare software:
          

          

            

              Where AI Excels:
              
    
                
  • Rapid generation of comprehensive combinatorial boundary test cases (e.g. leap years, timezone offsets).
    • 
                
  • Instant schema formatting into executable Playwright step arrays.
    • 
                
  • Adversarial thinking: discovering edge-case race conditions (two patients booking slot 09:00:00 simultaneously).
    • 
              

            

            

              Where AI Misses (Why Human Review is Vital):
              
    
                
  • Hallucinating UI capabilities not in the codebase (e.g. inventing drag-and-drop calendars in naive prompts).
    • 
                
  • Over-optimistic assertions that assume third-party APIs (Stripe, Google Meet) never fail.
    • 
                
  • Incomplete knowledge of custom backend token salting schemes without codebase grounding.
    •
